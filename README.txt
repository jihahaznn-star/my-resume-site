GIT COMMANDS
Open Terminal/Command Prompt in this project folder and run:
git init
git add .
git commit -m "Initial resume site"
git branch -M main
git remote add origin https://jihahaznn-star.github.io/my-resume-site/
git push -u origin main

GITHUB PAGES
Repository > Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)
Click Save and wait for deployment.

Website address:
https://jihahaznn-star.github.io/my-resume-site/

ASSIGNMENT QUESTION: WHAT IS THE MISTAKE?
The command shown in the question uses:
https://github.com/<yourusername>/my-resume-site.git
The text <yourusername> is only a placeholder. It must be replaced with the student's actual GitHub username. If it is entered literally, Git will not connect to the intended repository. The same applies to the GitHub Pages URL: replace <yourusername> with the real username.
Also make sure the repository name in the remote URL matches the repository actually created on GitHub.
